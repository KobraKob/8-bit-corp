# Corporate Hierarchy & Department Roles (`docs/org.md`)

Pixel Corp features 46 default corporate agents structured into a realistic corporate hierarchy across 9 functional departments:

## Hierarchy Levels

- **Level 1 — Executive Leadership**: Chief Executive Officer (CEO)
- **Level 2 — Department Heads**: Chief Operating Officer (COO), Chief Technology Officer (CTO), Head of Design, Chief Marketing Officer (CMO), Chief Financial Officer (CFO)
- **Level 3 — Middle Management**: Engineering Manager, Design Manager, Marketing Manager, Editor-in-Chief, Finance Manager, Project Manager
- **Level 4 — Technical Leads & Shared Services**: Frontend Lead, Backend Lead, DevOps & Data Lead, UI/UX Lead, Visual Lead, Content Lead, SEO Lead, QA Reviewer, Corporate Librarian, On-demand Researcher, Proofreader, HR Recruiter
- **Level 5 — Associates & Specialists**: Developers, Designers, Copywriters, Analysts, Coordinators, Finance drafters

## Shared Company Charter
All agents operate under Pixel Corp's non-negotiable charter:
1. Be concise; output concrete deliverables using tools.
2. Never fabricate sources or data; flag uncertainty explicitly.
3. Write deliverable artifacts directly to the workspace filesystem.
4. If a task requires missing capabilities, consult HR/Recruiter to create a dynamic role under Special Projects.
